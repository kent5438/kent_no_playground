# 🌿 個人每日生活與飲食儀表板 (Personal Daily Life & Meal Dashboard)

採用**模組化（Widget / Plugin 架構）**設計的全端個人生活與三餐決策儀表板，將「**中央氣象署 (CWA) 天氣預報**」、「**住家周邊外食三選一 (Google Maps)**」、「**每兩小時自煮正餐推薦與歷史紀錄**」與「**全方位智慧採買清單模組（不限品類）**」拆分為獨立的後端服務模組與前端 UI 卡片元件，並使用輕量級 **SQLite** 資料庫搭配背景 **Cron Job 排程器**，實現定時自動更新與隔日歷史自動清理。伺服器預設綁定 **`0.0.0.0`**，啟動時自動印出區網連線提示，支援手機、平板與同網路下任何裝置直接瀏覽操作。

## 二、 快速安裝與啟動步驟

本專案經過特別設計，**僅需 Python 3 標準庫即可零依賴直接啟動**（無須額外編譯步驟），且在未填入外部 API 金鑰前會自動啟用內建的**新竹縣竹東鎮在地擬真資料與 25 道精選台灣家常食譜庫**，開箱即用！

### 步驟 1：複製環境變數檔 `.env`
```bash
cp .env.example .env
```
> 若您已有 **中央氣象署 CWA API Key**、**Google Maps Places API Key** 或 **Gemini LLM API Key**，請編輯 `.env` 填入；若暫不填寫，系統會自動使用內建擬真資料與竹東在地高評價餐廳庫運作。

### 步驟 2：啟動儀表板伺服器（預設綁定 `0.0.0.0`）
```bash
python3 app.py
```

### 步驟 3：開啟瀏覽器或手機跨裝置瀏覽
伺服器一律綁定為 `0.0.0.0`，啟動完成時終端機會自動印出本機與區網連線網址：
- 💻 **本機瀏覽**：**`http://0.0.0.0:8000`**
- 📱 **手機 / 同區網其他裝置瀏覽**：**`http://<終端機顯示之區網IP>:8000`**

## 三、 核心模組與排程規格說明

| 模組名稱 | 自動排程時間 (Cron Job) | 核心功能特色 |
| :--- | :--- | :--- |
| **模組 1：中央氣象署 (CWA) 天氣預報** | 每日 `06:00` 自動更新（亦提供手動重新整理按鈕） | • 預設地點為**新竹縣竹東鎮**，支援下拉選單隨時切換全台各縣市鄉鎮區（同步存入 `LocalStorage` 與 `SQLite`）。<br>• **每小時預報（未來 36 小時）**與**每週預報（未來 7 天）**一鍵切換，完整顯示氣溫（°C）、降雨機率/降雨量（mm）、風速（m/s & 級數）/風向。 |
| **模組 2：住家周邊外食三選一** | • `06:00` 更新**早餐**<br>• `10:00` 更新**午餐**<br>• `16:00` 更新**晚餐** | • 根據住家座標（預設新竹縣竹東鎮 `24.7376, 121.0887`，可於設定頁微調半徑與經緯度），篩選**營業中、評價 4.0 星以上**餐廳，隨機挑選不重複 3 間。<br>• 顯示店名、評分、距離、營業時段，並附上**一鍵開啟 Google Maps 導航**按鈕。 |
| **模組 3：每兩小時自煮正餐推薦與歷史紀錄** | • 每日 `06:00` 起每 2 小時 (`06:00`, `08:00`...`22:00`) 自動生成新一輪<br>• 每日 `00:00` / `05:59` 自動清空前日紀錄 | • 每輪生成 **5 道台灣家常下飯正餐**（確保連續兩輪不重複）。<br>• 點擊任一料理彈出**詳細食譜視窗**：含預估烹飪時間、**預設 2 人份**、**精確食材與調味料克數/匙數**、條列式步驟、**主廚火候小撇步**，並支援**一鍵匯入食材至採買清單**。<br>• 內建「**今日歷史紀錄時間軸**」分頁，保留當天所有時段推薦過的菜色，隔日自動清空保持資料庫輕量。 |
| **模組 4：全方位智慧採買清單模組（不限品類）** | 即時互動與 SQLite 永久保存 | • **通用物品新增 & 食譜匯入**：支援生鮮食材、日用清潔、居家百貨、3C家電、零食飲料、藥妝保健等任何品項，並可從自煮食譜一鍵匯入食材。<br>• **自動商品類型判斷**：透過規則庫或 LLM 自動判斷分類（亦支援手動隨時修改）。<br>• **自訂地點記憶與網購快速搜尋**：自動記憶所有輸入過的地點並提供 Autocomplete 與常用地點管理；若地點為網購平台（如 momo、蝦皮、PChome、酷澎等）自動產生帶入商品名稱的**快速搜尋連結**。<br>• **急迫性分級與雙檢視模式**：支援 `🔴 緊急`、`🟡 一般`、`🟢 不急`（預設依急迫性高低排序），提供「**依急迫性檢視**」與「**依購買地點分組檢視**」一鍵切換。<br>• **已購買歸檔與歷史紀錄**：勾選已購買（可選填金額）後自動轉存歷史紀錄，支援關鍵字搜尋與「**🔄 再次購買**」按鈕。 |

## 四、 如何新增未來的生活模組（如：高鐵時刻表、待辦清單、採買清單）

1. **後端**：在 `backend/modules/<your_module>/service.py` 繼承 `BaseModule`，實作 `on_cron_tick(now_dt)` 後於 `app.py` 呼叫 `registry.register(your_module)`。
2. **前端**：在 `frontend/js/widgets/<yourWidget>.js` 定義 `slotSelector: "#widget-slot-extensions"` 與 `mount(container)`，並於 `frontend/js/main.js` 呼叫 `widgetRegistry.register(YourWidget)` 即可自動掛載。
